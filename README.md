## 🤖 Telegram Bot - Дисциплина без силы воли

Telegram-бот с воронкой прогрева + полнофункциональная админ-панель прямо в ТГ.

### ✨ Возможности

**Для пользователей:**
- 5 вопросов воронки прогрева
- Персональные ответы на основе выбора
- Получение материалов

**Для админов** (`/admin`):
- 📊 Статистика воронки
- 👥 Список пользователей
- 🔍 Поиск по username/ID
- 📣 Рассылка всем
- 🔗 Изменение ссылок без перезагрузки
- 📥 Экспорт CSV

### 🚀 Быстрый старт

#### Локально:
```bash
pip install -r requirements.txt
python bot.py
```

#### Docker:
```bash
docker-compose up -d
```

### 📱 Команды

- `/start` - начать воронку
- `/admin` - админ-панель (391024857)
